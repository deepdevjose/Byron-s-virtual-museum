# Changelog

All notable project changes should be documented in this file.

## 1.0.0 - 2026-08-12

- Added development-only npm tooling while preserving the museum as a static
  WebGL application.
- Added GitHub Actions CI for catalog validation, JavaScript syntax checks,
  static smoke tests, linting, formatting, and Playwright browser tests.
- Added Playwright coverage for startup rendering, welcome UI, guided tour,
  credits, artwork detail modal behavior, and mobile touch controls.
- Added an MIT software license with explicit artwork and cultural-asset
  exclusions in `NOTICE.md`.
- Added performance benchmark documentation templates for future measured
  desktop and mobile results.
